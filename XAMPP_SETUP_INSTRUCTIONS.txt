===============================================
MKfinder XAMPP Setup Instructions
===============================================

STEP 1: Start XAMPP
-------------------
1. Open XAMPP Control Panel
2. Start Apache
3. Start MySQL
4. Make sure both are running (green status)

STEP 2: Import Database
------------------------
1. Open your browser and go to: http://localhost/phpmyadmin
2. Click on "New" in the left sidebar
3. Or click on "Import" tab at the top
4. Click "Choose File" and select: mkfinder_database.sql
5. Scroll down and click "Go" button
6. Wait for success message: "Import has been successfully finished"

STEP 3: Verify Database
-----------------------
1. In phpMyAdmin left sidebar, click on "mkfinder" database
2. You should see these tables:
   - users
   - user_sessions
   - species
   - uploads
   - identifications
3. Click on "species" table to verify 3 bird species are inserted
4. Click on "users" table to verify test account exists

STEP 4: Copy Files to XAMPP
----------------------------
1. Copy ALL your project files to: C:\xampp\htdocs\mkfinder\
   (or wherever your XAMPP htdocs folder is located)
2. Make sure ALL files are copied including:
   - index.html
   - login.html
   - signup.html
   - All PHP files
   - styles.css
   - script.js
   - uploads folder (create if doesn't exist)
   - images folder

STEP 5: Test the Application
-----------------------------
1. Open browser and go to: http://localhost/mkfinder/index.html
2. Click "Login" in navigation
3. Use test account:
   Email: test@mkfinder.com
   Password: test123
4. After login, try uploading a bird image
5. System should identify the bird species

TROUBLESHOOTING
---------------
If login doesn't work:
- Check database was imported successfully in phpMyAdmin
- Verify MySQL is running in XAMPP
- Check error.log file in your project folder

If upload doesn't work:
- Make sure "uploads" folder exists
- Check folder permissions (should be writable)
- Check PHP error logs in XAMPP\apache\logs\error.log

DATABASE CONNECTION SETTINGS
-----------------------------
The application uses these default XAMPP settings:
- Host: localhost
- Port: 3306
- Database: mkfinder
- Username: root
- Password: (empty)

If your XAMPP uses different settings, update database.php file.

IMPORTANT NOTES
---------------
- Default test account: test@mkfinder.com / test123
- Change password after first login for security
- Bird identification works in demo mode (random species)
- 3 supported species: American Robin, Blue Jay, Northern Cardinal
- Maximum upload size: 5MB
- Supported formats: JPG, PNG, WEBP
